# Искусственный интеллект в работе и разработке

Раздел о практическом использовании AI-ассистентов и агентов: как ставить задачи, писать промпты и навыки, выбирать степень автономности, пользоваться GitHub Copilot CLI и проверять пользу и риски.

**Главная мысль:** результат зависит не от одной «идеальной роли» или длинного промпта, а от подходящего способа решения, качественного контекста, ясно заданного критерия успеха, прав доступа и независимой проверки.

## Быстрый выбор инструмента

| Если нужно… | Начать с… |
|---|---|
| Получить разовый ответ или выполнить узкую задачу | Обычного запроса с контекстом и критериями готовности |
| Постоянно применять простые правила проекта | Инструкций репозитория/пути |
| Иногда повторять определённый процесс | Skill |
| Выделить специалиста с определёнными ограничениями и способом работы | Custom agent |
| Дать модели новую операцию во внешней системе | Tool или MCP-интеграции с минимальными правами |
| Автоматически запускать проверяемое действие на событие жизненного цикла | Hook; особенно осторожно с shell-командами |
| Решить фиксированную цепочку действий | Детерминированного workflow, а не автономного агента |
| Пусть модель выбирает следующий шаг по меняющимся результатам | Агента, если ожидаемая гибкость оправдывает цену, задержку и риск |

## Принципы раздела

- Начинать с простого решения; добавлять инструменты, агентность и параллелизм только при измеримой необходимости.
- Роль помогает сфокусировать инструкцию, но не доказывает квалификацию агента и не обеспечивает независимость.
- Давать агенту только нужный контекст и права. Текст из кода, документов или веба может содержать ошибочные либо враждебные инструкции.
- Проверять результат по наблюдаемым критериям, а не по уверенности, многословию или самооценке модели.
- Для меняющихся функций Copilot проверять актуальную официальную документацию и `/help`; продуктовые возможности здесь привязаны к дате источников и могут устареть.

## Актуальность источников

Внешние источники проверены **11 октября 2026 года**. Общие инженерные принципы отделены от описаний функций Copilot CLI. Документация продукта быстро меняется; CLI-документация прямо рекомендует сверяться с `/help`. Эти заметки — практическое руководство, не гарантия качества или юридическая/безопасностная сертификация.
